# Task Management System

A full-stack task management application built using React, Node.js, Express, and MongoDB.

## Features

- User Registration & Login
- JWT Authentication
- Create, Read, Update, Delete Tasks
- Protected Routes
- PDF File Upload
- MongoDB Database
- React Frontend
- Task Dashboard

## Tech Stack

### Frontend
- React
- Axios

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- Multer

## API Endpoints

### Auth

POST /api/auth/register

POST /api/auth/login

### Tasks

GET /api/tasks

POST /api/tasks

PUT /api/tasks/:id

DELETE /api/tasks/:id
